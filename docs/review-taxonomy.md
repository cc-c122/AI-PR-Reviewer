# Review Taxonomy

Severity levels:

- `critical`: likely security incident, data corruption, or production outage.
- `major`: likely bug, compatibility issue, or meaningful quality risk.
- `minor`: maintainability or localized improvement.
- `info`: contextual note or human-confirmation reminder.

Categories:

- `bug`
- `security`
- `performance`
- `maintainability`
- `test`
- `docs`
- `style`
